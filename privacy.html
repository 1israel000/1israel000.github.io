Privacy policy

Last updated: 17.11.2026

The tools described on this site (rec-uploader and gog) are personal tools used only by their owner, with the owner's own Google account.

What data is accessed

With the owner's consent, the tools access the owner's Google account data through Google APIs (for example Google Drive, Gmail, Calendar and Sheets). rec-uploader reads audio recordings stored on the owner's phone and uploads them to a folder in the owner's Google Drive.

How data is used

Data is used only to perform the action the owner requested, such as uploading a recording to Drive. Data is sent only between the owner's devices and Google's servers.

Sharing and storage

No data is sold, shared with third parties, used for advertising, or stored on any server operated by the developer. There is no analytics or tracking.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
